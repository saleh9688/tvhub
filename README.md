# TV Hub — نسخة الويب

واجهة عربية لتشغيل قنوات ومباريات كتالوج SportzX داخل **أي متصفح** — بلا محاكي،
بلا برامج، بلا تثبيت. تعمل على ويندوز وماك ولينكس وحتى الجوال.

---

## التشغيل السريع

### أ) من الإنترنت (أي جهاز)
افتح الرابط المنشور في المتصفح. خلاص.

### ب) محليًا بلا إنترنت
انقر **`start.cmd`** — يشغّل خادمًا محليًا ويفتح المتصفح تلقائيًا على
`http://localhost:8731`.

> لا تفتح `index.html` بالنقر المزدوج: المتصفح يمنع قراءة ملفات JSON عبر
> بروتوكول `file://`. لا بد من خادم.

لتشغيله يدويًا:
```
node server.cjs 8731
```

## المشغّل

- **HLS** عبر `hls.js` · **DASH** عبر `dash.js`
- **ClearKey**: مصادر Widevine التي يحمل حقل `api` فيها زوج `KID:KEY` صالح
  تُفكّ **محليًا في المتصفح** بلا سيرفر ترخيص.
- **التبديل التلقائي**: عند فشل مصدر ينتقل للتالي (حتى 12 محاولة) مع عرض ما جرى.
- الترتيب يقدّم المصادر المتحقَّقة أولًا، فيكون أول ضغط هو الأرجح.

## ترتيب ثقة المصادر

1. **قياس هذا الجهاز** — الفحص الحيّ هو المرجع، وصلاحيته 6 ساعات.
2. **الفحص المدمج** — `data/verified.json` من فحص على جهاز آخر.

لو قاس جهازك مصدرًا وفشل، لا نرجع لحكم الملف المدمج — الحكم للقياس.

## حدود معروفة

- **CORS**: المتصفح يمنع قراءة مصادر لا ترسل ترويسة السماح. بعض المضيفات
  تعمل في تطبيق أندرويد ولا تعمل في المتصفح — هذا قيد المتصفح لا التطبيق.
- **المصادر الميتة**: الكتالوج لقطة زمنية. أغلب المضيفات ميتة، والعامل منها
  يظهر موسومًا بـ`✓`.
- **المفاتيح التالفة**: بعض الناشرين يحقن بايتات عشوائية وسط قيمة `api`،
  فتُتخطّى تلقائيًا بدل عرض رسالة طلب سيرفر ترخيص.

## 🔒 صفحة الدخول وقفل الموقع

الموقع محمي بصفحة دخول (يوزر + باسوورد). لكن الحماية **ليست** مجرّد شاشة
تخفي المحتوى — المحتوى نفسه مشفّر.

### كيف يعمل

1. `set-login.cmd` تختار منها بيانات الدخول → يُبنى ملف **`data/vault.enc`**
2. المحتوى (الكتالوج + التصنيفات + نتائج الفحص) يُضغط بـ gzip ثم يُشفّر
   بـ **AES-256-GCM** بمفتاح مشتقّ من كلمة المرور بـ **PBKDF2-SHA256 ×300,000**
3. ملفات JSON الصريحة تُنقل إلى `_private/` خارج مجلد النشر
4. النشر يرفع `vault.enc` فقط ويحذف النسخ الصريحة من المستودع

### لماذا هذا قفل حقيقي

لو أحد تجاوز شاشة الدخول (عدّل JavaScript من أدوات المتصفح، أو خزّن مفتاحًا مزيفًا)
فلن يجد **شيئًا** ليقرأه: ملفات البيانات لم تبقَ على الموقع أصلًا، وما نُشر
هو كتلة مشفّرة لا تُفكّ إلا بالمفتاح الصحيح.

ولو سحب `vault.enc` وحاول فكّه على جهازه، فهو يواجه 300,000 دورة PBKDF2
لكل محاولة — أي أن قوة القفل تعتمد على **قوة كلمة المرور**.

### ما لا تحميه

- **التجريب الغاشم**: من يحصل على `vault.enc` يستطيع تجريب كلمات مرور
  بلا اتصال بالموقع. لذلك اختر كلمة مرور طويلة (12 حرفًا أو أكثر).
- **مسار الدخول نفسه** ليس سرًّا: يراه من يفتح الصفحة المصدرية. المشفّر هو البيانات.
- ملفات أندرويد (`tvhub-data`) منشورة منفصلة وغير مشفّرة — لا علاقة لها بهذا القفل.

### تغيير بيانات الدخول

انقر **`set-login.cmd`** → اكتب اليوزر وكلمة المرور → ثم:

```
node deploy.cjs
```

القفل الجديد يسري مباشرة. الجلسات المفتوحة على أجهزة أخرى تنتهي عند إغلاق
التبويب أو بعد 12 ساعة، لكن الأجهزة التي حمّلت البيانات سابقًا تحتاج تحديث الصفحة.

### تفاصيل تقنية

| | |
|---|---|
| الاشتقاق | PBKDF2-SHA256 · 300,000 دورة · ملح 16 بايت لكل قفل |
| التشفير | AES-256-GCM · nonce 12 بايت · AAD = `tvhub-vault-v1` |
| الضغط | gzip قبل التشفير (2.33MB → 332KB → 443KB base64) |
| الجلسة | المفتاح المشتقّ في `sessionStorage` فقط · 12 ساعة · يُمحى بالخروج |
| كلمة المرور | **لا تُخزَّن في أي مكان** — لا في الملف ولا في المتصفح |
| التحقّق | وسم GCM: كلمة مرور خطأ يفشل فكّها رياضيًا، لا مقارنة نصية |

### ملفات

```
tools/make-lock.cjs    يبني الخزنة من بيانات الدخول التي تختارها
tools/check-lock.cjs   يفحص الموقع المنشور ويؤكّد أن القفل سليم
js/auth.js             بوابة الدخول في المتصفح (Web Crypto)
set-login.cmd          نقرة واحدة لتغيير بيانات الدخول
data/vault.enc         الخزنة المنشورة (المحتوى المشفّر)
_private/              النسخ الصريحة — خارج النشر، لا يُرفع
```

فحص ما بعد النشر:

```
node tools/check-lock.cjs --user <اليوزر> --pass <كلمة المرور>
```
